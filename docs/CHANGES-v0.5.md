# v0.5 — readability

Small uppercase subheadings now use 14 px semibold system sans-serif with restrained tracking. Supporting explanations use 15–16 px type and increased line spacing; captions have a 12 px minimum. Secondary text is brighter on dark surfaces, and resource-section captions use a darker color on the light background.

Form inputs are 16 px. Camera buttons, event shortcuts, resource labels, event cards, result tables, calculator copy, evidence metadata and footer text are larger. Canvas annotations use a 12 px minimum. Layouts wrap controls and stack mobile telemetry rather than squeezing the text. Short mobile viewports use compact chapter selection so enlarged story copy does not compete with a pinned map.

This is a presentation change. Vehicle assumptions, numerical physics, traffic, resource accounting and replay outcomes are unchanged. Visual verification checks desktop and mobile typography, width overflow, story fit and functioning replay controls.
